# Algophony Framework Dashboard

Next.js dashboard for browsing the Algophony Framework Atlas, procedural generations, listening reports, benchmark scores, references, and export files.

## Requirements

- Node.js compatible with Next.js 16.
- The repository data files in the project root.

## Commands

```bash
npm install
npm run dev
npm run build
```

The local app runs at `http://localhost:3000`.

## Data Root

By default the app expects to be run from `apps/web` and reads data from the repository root two directories above it. To use another checkout or mounted dataset:

```bash
ALGOPHONY_DATA_ROOT=/path/to/algophony npm run dev
```

## Studio (Playground)

The Playground (generation + upload) is gated and disabled by default. To enable
it locally:

```bash
ALGOPHONY_ENABLE_STUDIO=true npm run dev
```

Studio endpoints (`/api/generate`, `/api/upload`) require either:

- the request to originate from `localhost` / `127.0.0.1` (the default), OR
- a matching `x-studio-token` header when `ALGOPHONY_STUDIO_TOKEN` is set
  (required if you expose the dashboard behind a proxy).

Concurrent Python subprocesses are capped by `ALGOPHONY_STUDIO_MAX_CONCURRENT`
(default `2`). Excess requests get `503 Retry-After: 15`.

## Routes

- `/` overview
- `/atlas` Atlas category summary
- `/prompts` prompt filters
- `/prompts/[id]` prompt detail
- `/generations` generation list
- `/generations/[id]` audio playback and metadata
- `/reports` report list
- `/reports/[id]` AKOÚŌ report detail
- `/comparison` score comparison
- `/providers` provider registry and configuration status
- `/benchmark` suite metadata
- `/observatory` data visualizations and field data
- `/playground` interactive generation and listening (requires `ALGOPHONY_ENABLE_STUDIO=true`)
- `/export` export file links

## Release Notes

The current dashboard labels the benchmark as a procedural pilot. It must not present the current score table as a mature ML model comparison until ML generations are present in `generations/metadata/generations-v0.1.jsonl` and validated by the strict release gate.

Provider status is read from `benchmark/exports/provider-status.json`, generated by:

```bash
python3 scripts/generate_matrix.py --list-providers --json > benchmark/exports/provider-status.json
```
